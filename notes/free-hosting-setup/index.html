Notes / Setup

Build it, back it up, and serve it,
all for free.

Here’s the recipe: an AI tool writes the code, GitHub keeps every version safe, and Vercel puts it on the internet under your own domain. There’s no server to maintain and nothing to pay for. The AI tool and GitHub aren’t really required, but I recommend it. If you’re using an AI tool, it can handle GitHub and the deploys for you.

The Setup

Build (optional)

Talk to it in plain language, the same way you’d brief a person. “Make the headline bigger,” “add a contact page,” “swap this color.” When it looks right, just ask it to commit, merge, and deploy. Easy peasy.

Save (optional)

Every change gets saved as a snapshot in GitHub. Unlimited undo for the whole site, plus a free backup that isn’t sitting on one laptop. Break something? Roll back to yesterday’s version in a click. Skip it and everything you’ve built lives in exactly one place, which is fine until the day it isn’t.

Ship

Vercel watches that GitHub folder and publishes automatically. Save a change, and the live site updates within seconds. Point your own domain at it and you’re done — plus real analytics for free, no extra install, no extra cookie banner.

What it costs

Basically nothing. The AI tool, GitHub, and Vercel all have free tiers generous enough for a personal site. The one real cost is the domain name itself, and you’d pay that no matter who’s hosting.

Worth noting

It comes off professional with no badging or watermarks.

Both Vercel and GitHub Pages let you hook up a custom domain for free, with zero of their branding attached. No “Powered by” subdomain, no badge in the footer. Once your domain’s connected, there’s nothing on the page telling anyone who’s hosting it. It’s just your site.

Common questions

So when would I actually have to pay?

Vercel’s free “Hobby” tier is built for personal, non-commercial sites, which covers a portfolio, a blog, most side projects. It’s the same infrastructure real companies run production sites on, so it’s fast and ad-free with no catch, just plenty of bandwidth and build minutes for that use case. You’d outgrow it if the site starts making you money directly (Vercel asks commercial projects to move to a paid plan), or if traffic gets big enough to blow past the usage caps, which is a good problem to have and not something a personal site runs into by accident. GitHub Pages works the same way: free for reasonable personal use, with soft limits behind it.

How long can I count on this being free?

Vercel and GitHub can change their pricing or terms whenever they want, nobody can promise they won’t. The reassuring part is that none of this locks you in. The site itself is just HTML, CSS, and JS sitting in a folder. If either of them ever stopped making sense, you’d point that same folder at Netlify, Cloudflare Pages, or anywhere else that hosts static files, and be back up in an afternoon.

What if I want to drop or change my AI tool later?

Go for it. It just writes normal code files into GitHub. Any developer, or any other AI tool, can pick up right where you left off.

Vercel or GitHub Pages, which one?

Both are free, and both let you attach a custom domain with none of their branding. GitHub Pages deploys straight from the repo, no separate account to set up, which is about as simple as it gets. Vercel’s a bit more full featured: nicer previews, easier domain setup, analytics built in, and honestly just as easy once you’ve got an AI tool doing the setup with you.

Do I need to know how to code?

Nope, that’s the whole point of the first step. You do need someone comfortable following a short setup guide once, to wire the three pieces together.
